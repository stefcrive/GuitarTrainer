# Visualising the Fretboard Pt 1 - Extracted Notes

## Summary
This lesson teaches a practical system for visualising the guitar fretboard focused on intervals rather than large scale or chord shapes. It is useful for guitarists aiming to improve improvisation, especially when playing over chord changes. The tutorial contrasts traditional position-based systems like CAGED and three-note-per-string with an interval-based approach that simplifies fretboard navigation and enhances musical decision-making.

## Core Idea
The main method taught is to visualize the fretboard by identifying root notes and mapping all intervals within one octave around them. Instead of relying on large scale or chord shapes, the player learns small, manipulable interval shapes (e.g., root to flat 3, root to 5th) and applies these shapes anywhere on the neck relative to the nearest root note. This approach allows for efficient, conscious note choices and easier improvisation over chord changes.

- Practice playing intervals ascending and descending from every root note.

## Fretboard Visualization Method
1. **Root Note Identification**: Know where every root note is on the fretboard and be able to find it instantly.
2. **Interval Mapping Within One Octave**: Learn the shapes of intervals (flat 3, 5, flat 7, etc.) relative to the root note within a single octave.
3. **Small Chunks of Information**: Focus on small interval shapes rather than large scale or chord shapes.
4. **Tuning Adjustments**: Modify interval shapes when crossing the G-B and G-E strings in standard tuning by moving the higher note up one fret.
5. **Visualize from Nearest Root**: When playing, always visualize intervals relative to the closest root note to maximize efficiency.
6. **Interval Cataloguing**: Memorize multiple shapes for each interval and practice them all over the fretboard.
7. **Apply to Scales and Chords**: Use interval knowledge to construct scales and arpeggios from formulas rather than memorizing box patterns.
8. **Improvisation**: Improvise by consciously choosing intervals and moving between root notes, rather than relying on scale shapes.
9. **Practice Progression**: Start with root notes, then flat 3, 5, flat 7, add the 4th for minor pentatonic, then learn all other intervals.
10. **Use Resources**: Refer to provided PDF charts for interval shapes in your tuning.
